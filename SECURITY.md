# Security policy

Charon is an experimental local-first side project. Security fixes target the
latest published version only.

Report a suspected vulnerability through
[GitHub private vulnerability reporting](https://github.com/SimonHazard/Charon/security/advisories/new).
Do not include Note text, selected text, clipboard contents, Attachment bytes,
private keys, tokens, or sensitive filesystem paths in a public issue.

Ordinary compatibility and functional defects can use GitHub Issues. Include
the operating system, desktop session where relevant, Charon version, source
application, reproduction steps, and expected versus actual behavior without
including captured content.
