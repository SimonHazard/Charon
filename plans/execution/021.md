# Exécution du Plan 021

Le Plan 021 a été exécuté sur la branche
`codex/021-portable-persistence`, à partir de `37d6f74`. Le drift check demandé
n’a signalé aucune modification dans le périmètre et les extraits du plan
correspondaient au code actif.

## Réalisation

- Les chemins canoniques Windows sont simplifiés à la frontière de stockage,
  puis les chemins relatifs du Workspace sont joints composant par composant.
- Le stockage mémoire conserve désormais exclusivement des clés séparées par
  `/`, et le filtre du watcher raisonne sur les composants natifs du chemin.
- Les préférences utilisent le mode `0o600` et la synchronisation du dossier
  uniquement sous Unix ; Windows ne tente plus d’ouvrir un dossier comme un
  fichier.
- Le bootstrap Linux retombe explicitement sur `~/Documents` quand le dossier
  Documents n’est pas résolu, avec une erreur localisée et dédiée si le dossier
  personnel est lui aussi indisponible.
- Les chemins d’Attachment produits pour `Copy as Markdown` n’exposent plus de
  préfixe Windows verbatim.
- Les tests couvrent les préfixes verbatim, les clés mémoire, le filtre du
  watcher, les permissions des préférences, le chemin d’erreur dédié, le chemin
  canonique géré et la réouverture réelle d’un Workspace avec conservation
  exacte du corps d’une Note.

## Vérifications

- `cargo fmt --manifest-path apps/desktop/src-tauri/Cargo.toml --check` : réussi.
- `cargo clippy --manifest-path apps/desktop/src-tauri/Cargo.toml --all-targets --locked -- -D warnings` : réussi.
- `cargo test --manifest-path apps/desktop/src-tauri/Cargo.toml --locked` :
  réussi, avec 79 tests unitaires Rust et 12 tests de contrat Workspace actifs.
- `bun run typecheck` : réussi.
- `bun run test` : réussi, 22 fichiers et 79 tests desktop, puis le site
  statique vérifié.
- `bun run check` : réussi intégralement.
- Les contrôles structurels du plan passent : aucun `self.root.join(` dans le
  stockage réel, un seul `fs::canonicalize` dans le helper, les deux protections
  Unix des préférences sont présentes, et le watcher ne filtre plus avec des
  séparateurs codés en dur.

## Preuve restante

Cette exécution prouve la construction portable et les chemins concernés sur
macOS. L’exécution runtime sur Windows et Linux reste volontairement à établir
par la matrice CI du Plan 022 puis par les matrices physiques applicables ; ce
n’est pas un critère physique du Plan 021.

Le commit unique demandé porte le message
`fix(workspace): make persistence portable to windows and linux`.
